# Pixel Tracer

Pixel Tracer est un éditeur de dessin vectoriel basé sur le texte, conçu pour fonctionner directement dans un terminal. Ce projet permet de manipuler des formes géométriques complexes via une interface en ligne de commande (CLI) et de visualiser le rendu sous forme de caractères ASCII.

Ce projet a été réalisé par **Noah Lavocat** dans le cadre de la matière **Maintenance Applicative** (BUT3 Informatique, Semestre 6) à l'**IUT de Vélizy**.

---

## Installation et Lancement

L'application est développée en Java. Pour lancer le programme, vous devez exécuter la classe principale `App.java` située dans le package `shape`.

Utilisez la commande suivante depuis la racine du projet :

```bash
java src/shape/App.java
